# PromptPolish

Chrome extension (Manifest V3) that rewrites rough prompt drafts on ChatGPT and Claude.
Select text in the prompt box → pick **Preserve**, **Improve** or **Rewrite** → the selection is replaced with the rewritten prompt (via OpenAI `gpt-4o-mini`).

## Install (unpacked)
1. Go to `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and choose this folder.
3. Click the PromptPolish icon, paste your OpenAI key (`sk-...`), and click **Save**.
4. Open or refresh chatgpt.com or claude.ai, type a draft, select it, and pick a mode.
